# フィードバック・演出

> [ドキュメント一覧](../../README.md) / 区分: 要件

[CCC要件書](../overview.md)から分離した、ユーザー操作（入力）時、並びにミッション成功・失敗時の視覚・音響フィードバックおよび各種演出の仕様について説明する。

## 入力フィードバック

- **数字の変更**: 数字変更時は、該当する数字カードに対してカードめくりのアニメーション（`CardFlipAnimation`）を適用し、視覚的に強調すること。
- **タッチ領域**: 各ボタン・タッチ領域は、タップ（PointerDown）時に押し込みアニメーションを出力すること。
- **演算子の変更**: 演算子変更時は、中央の共有演算子および左右両プレイヤーの `OPERATOR` 領域を短時間強調表示すること。

## 成功（CLEAR）演出

- 画面上に `CORRECT!` のポップアップメッセージをオーバーレイ表示すること。
- クリアを達成した最終式およびその計算結果を表示すること。
- 演出の表示時間は約 `0.8秒` とし、共通 Config 設定により一括調整可能とすること。

## 失敗（MISS / GAME OVER）演出

- **Life が残っている場合**: 画面上に `MISS!` を表示し、ライフアイコンが減少するアニメーションを再生すること。
- **Life が 0 になった場合**: `GAME OVER` を画面上に表示すること。
- 提出（Submit）された最終式を表示すること。
- 「この式なら正解」というガイダンスと共に、正解模範例（`AnswerExample`）の式および計算結果を表示すること。
- `ShowCurrentAnswer` が `false`（非表示設定）であっても、失敗時の回答例は必ず画面上に表示すること（`ShowCurrentAnswer` は Gameplay 中の `CurrentExpression` リアルタイム計算結果表示のみを制御するため）。
- 失敗演出の表示時間は約 `3秒` とすること。

※演出アニメーション・画像アセット・効果音の再生処理は、ゲームの判定ロジックから完全に分離されたプレゼンテーション層で実装すること。
