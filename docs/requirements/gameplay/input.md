[CCC要件書](../overview.md)から分離した、数字・演算子の変更とマルチタッチ入力の仕様。

## 数字の変更

数字は設定範囲内を1ずつ昇順に循環する。

```text
最小値 → 最小値+1 → … → 最大値 → 最小値
```

1〜5の場合：

```text
1 → 2 → 3 → 4 → 5 → 1
```

## 演算子の変更

```text
＋ → − → × → ÷ → ＋
```

演算子はPLAYER AとPLAYER Bの共有値であり、どちらが操作しても同じ演算子が進む。

## タッチ領域

本実装の入力対象はマルチタッチ対応スマートフォンのタッチ操作だけとする。キーボード、ゲームパッド、マウス操作は必須仕様に含めない。

| タッチ領域 | 動作 |
| --- | --- |
| PLAYER_A_NUMBER | 左の数字を1段階進める |
| PLAYER_A_OPERATOR | 共有演算子を1段階進める |
| PLAYER_B_NUMBER | 右の数字を1段階進める |
| PLAYER_B_OPERATOR | 共有演算子を1段階進める |
| SUBMIT | 現在の式を確定し、即座にMission判定を要求する |

指が離れた瞬間ではなく、画面に触れた瞬間に処理する。

## マルチタッチ

- 複数の指を独立した入力として処理する。
- 左右の数字を同時タップした場合、両方を変更する。
- 左右のOPERATORを同時タップした場合、共有演算子を2段階進める。
- 同じボタンへの2本指入力も2入力として扱う。
- タッチ後の疑似Clickで二重入力しない。
- Submit受付後または時間切れ後の入力は無視する。
