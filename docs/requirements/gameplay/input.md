# 入力仕様

> [ドキュメント一覧](../../README.md) / 区分: 要件

[CCC要件書](../overview.md)から分離した、数字・演算子の変更挙動およびマルチタッチ入力に関する詳細仕様について説明する。

## 数字の変更ルール

数字ボタンをタップすると、設定された数字範囲内を1ずつ昇順にサイクリック（循環）変化すること。

```text
最小値 → (最小値 + 1) → … → 最大値 → 最小値
```

例: 数字範囲が `1〜5` の場合

```text
1 → 2 → 3 → 4 → 5 → 1
```

## 演算子の変更ルール

演算子ボタンをタップすると、以下の順序でサイクリックに変化すること。

```text
＋ → − → × → ÷ → ＋
```

※演算子は PLAYER A と PLAYER B で共有される単一のオブジェクト（値）であり、どちらのプレイヤー領域の演算子ボタンを操作した場合でも、同一の共有演算子が1ステップずつ更新されること。

## タッチ領域と動作

本ゲームの入力対象は、マルチタッチに対応したスマートフォンにおけるタッチ操作のみを想定する。キーボード、ゲームパッド、マウスによる操作は標準動作仕様には含めないこと。

| タッチ領域識別子 | 割り当て動作 |
| --- | --- |
| `PLAYER_A_NUMBER` | 左側の数字を1段階繰り上げる |
| `PLAYER_A_OPERATOR` | 共有演算子を1段階進める |
| `PLAYER_B_NUMBER` | 右側の数字を1段階繰り上げる |
| `PLAYER_B_OPERATOR` | 共有演算子を1段階進める |
| `SUBMIT` | 現在表示されている式を確定し、即座にミッションの判定を要求する |

※タップ入力の検知・発火タイミングは、指が画面から離れた瞬間（PointerUp）ではなく、**画面に触れた瞬間（PointerDown）** とすること。

## マルチタッチの挙動

- 画面に接触した複数の指を、それぞれ独立した個別の入力イベントとして並行処理すること。
- 左右の数字ボタン（`PLAYER_A_NUMBER` と `PLAYER_B_NUMBER`）を同時タップした場合、両方の数字が即座に変更されること。
- 左右の演算子ボタン（`PLAYER_A_OPERATOR` と `PLAYER_B_OPERATOR`）を同時タップした場合、共有演算子は2段階進むこと。
- 同一のボタン領域に対して2本の指で同時入力がなされた場合も、2回の独立した入力として処理すること。
- タッチ入力検知後に発生するブラウザ／OS標準の疑似クリック（`Click`）イベントによる二重入力を防ぐ構成とすること。
- 送信完了（`Submit` 受付完了）後、および制限時間切れ（タイマー終了）後のあらゆる入力操作は無視すること。
