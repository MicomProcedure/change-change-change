# 式と数値計算

> [ドキュメント一覧](../../README.md) / 区分: 要件

[CCC要件書](../overview.md)から分離した、式の構造および正確な数値計算・画面表示の仕様について記述する。

## 式の構造

式の基本的な構成要素の並び順は固定とする。

```text
左の数字 [演算子] 右の数字
```

左右の数字を入れ替えたり、式の構造自体を変更したりする操作は存在しない。

## 正確な数値計算と判定

ミッション（Mission）の判定には画面表示用に丸めた数値ではなく、計算結果の正確な有理数（Rational）を使用すること。

### 0除算の扱い

- **表示**: `？`
- **Mission判定**: 必ず失敗とする。
- **NegatedMission**: 反転条件（NegatedMission）であっても成功扱いとはしない（失敗のままとする）。

### 計算結果の表示ルール

計算結果は分数表記を使用せず、小数点以下第2桁まで表示すること。小数点第3位以降に値が続く場合は四捨五入などの丸めを行わずに切り捨て、末尾に `……` を付与すること。

| 内部値 | 表示文字列 |
| --- | --- |
| `2/1` | `2.00` |
| `1/2` | `0.50` |
| `1/4` | `0.25` |
| `1/8` | `0.12……` |
| `1/3` | `0.33……` |
| `-2/3` | `-0.66……` |
| 0除算 | `？` |

- **ゼロパディング**: 整数および有限小数は、不足している小数桁を `0` で補正表示すること（例: `2` → `2.00`）。
- **`ShowCurrentAnswer` の設定**:
  - `GameplayConfig` の `ShowCurrentAnswer` フィールドは、現在の式（`CurrentExpression`）を評価した計算結果をゲームプレイ（Gameplay）中に表示するかどうかを制御する。
  - **Easy**: `true`（表示する）
  - **Normal / Hard**: `false`（非表示）
  - `ShowCurrentAnswer == false` の場合でも、解答失敗後の正解例（`AnswerExample`）は画面に表示すること。
  - **注意**: 表示用の文字列を Mission のクリア判定に使用してはならない。

### 剰余と小数桁

負数の剰余（mod）演算は、ユークリッド剰余として以下のように常に正規化すること。

```text
0 ≤ M < N
-1 mod 5 = 4
```

有限小数の末尾には `0` が連続して続くものとして小数桁を扱うこと。小数桁の算出にあたっては丸めを行わず、分子と分母から筆算方式で導出すること。
