[CCC要件書](../overview.md)から分離した、式の構造と正確な数値計算・表示の仕様。

## 式の構造

式の順番は固定する。

```text
左の数字 [演算子] 右の数字
```

左右を入れ替えたり、式の順番を変更したりする操作は存在しない。

## 正確な数値計算

Mission判定には表示用に丸めた値を使用せず、計算結果を正確な有理数として扱う。

### 0除算

- 表示：`？`
- Mission判定：必ず失敗
- NegatedMissionでも成功にしない

### 表示

計算結果は分数表記を使用せず、小数点以下2桁まで表示する。第3位以降に値が続く場合は丸めずに切り捨て、末尾へ`……`を付ける。

| 内部値 | 表示 |
| --- | --- |
| `2/1` | `2.00` |
| `1/2` | `0.50` |
| `1/4` | `0.25` |
| `1/8` | `0.12……` |
| `1/3` | `0.33……` |
| `-2/3` | `-0.66……` |
| 0除算 | `？` |

整数と有限小数は不足する桁を0で補う。GameplayConfigの`ShowCurrentAnswer`は、現在のCurrentExpressionを評価した計算結果をGameplay中に表示するかを表す。Easyではtrue、NormalとHardではfalseとする。`ShowCurrentAnswer == false`でも失敗後のAnswerExampleは表示する。表示用の文字列をMission判定に使用しない。

### 剰余と小数桁

負数の剰余はユークリッド剰余として正規化する。

```text
0 ≤ M < N
-1 mod 5 = 4
```

有限小数の末尾には0が続くものとして小数桁を扱う。小数桁は丸めず、分子と分母から筆算方式で求める。
